# velority.cloud · Demos de clientes

Cada demo va en su propia carpeta y se ve en `https://velority.cloud/<nombre-de-la-empresa>/`.

```
<nombre-de-la-empresa>/
  index.html
  img/        (fotos de la demo)
```

- Nombre de carpeta en minúsculas, sin tildes ni espacios (`ll-joyeria`, `peluqueria-ana`).
- Cada `index.html` lleva `<meta name="robots" content="noindex, nofollow">` para que no salga en Google.
- La portada (`/`) no enlaza a ninguna demo: cada cliente solo ve la suya con su enlace.
